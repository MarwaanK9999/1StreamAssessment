### Requirements
- Ensure that you have Python 3.x installed on your device.

- These are three small applications that run independently.

# 1. String Reversal Python Application

This is a simple Python command-line application that reverses a string that is input by the user. It also includes unit tests to make sure that it works as intended.

### To run the application:
1. Clone this repository or download the files.
   - This might not run in your IDE if your username contains special character, if so, continue the steps below.
2. Open your command-line interface and navigate to the folder where `stringReverse.py` is located.
3. Run the command:
   python stringReverse.py
4. You can also run the test using the command:
   python -m unittest stringReverseTest.py

### Application Flow
1. Application starts.
2. The user inputs a string.
3. The application processes the string.
4. The reversed string is displayed to the user.
5. End of application.

# 3. Full Name Sorter Python Application

This Python application sorts the names and surnames that are inout by the user by making use of a Bubble Sort algorithm.

### To run the application:
1. Clone this repository or download the files.
   - This might not run in your IDE if your username contains special character, if so, continue the steps below.
2. Open your command-line interface and navigate to the folder where `nameSorter.py` is located.
3. Run the command:
   python nameSorter.py
4. You can also run the test using the command:
   python -m unittest nameSorterTest.py

### Application Flow
1. Application Start
2. The user is prompted to enter the first name and surname of individuals.
3. The user is prompted to input the first name and surname. 
4. The user repeats the input for additional names and surnames.
5. To stop entering names, the user types exit when prompted for the first name.
6. At this point, the application exits the input loop and proceeds to sorting using a Bubble Sort algorithm.
7. After sorting is complete, the program displays the sorted list.
8. End of Application.
9. The application ends after displaying the sorted list. The user can run the program again or exit.
